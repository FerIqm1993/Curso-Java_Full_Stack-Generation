# 🎯 Objetivos Pedagógicos: JavaScript

## Propósito del Módulo
Introducir la lógica de programación y la interactividad en la web, transformando sitios estáticos en aplicaciones dinámicas.

## Metas de Aprendizaje
1. **Sintaxis Básica:** Variables, tipos de datos, operadores, y control de flujo (if/else, loops).
2. **Funciones y Estructuras:** Creación de funciones (Arrow functions), arreglos y manipulación de objetos.
3. **DOM (Document Object Model):** Seleccionar elementos HTML, escuchar eventos (clicks, inputs) y modificar la interfaz en tiempo real.

## ¿Cómo saber que dominas esto?
Eres capaz de crear una aplicación sencilla de To-Do list (lista de tareas) que permita agregar, marcar como completadas y eliminar tareas, todo interactuando con la pantalla (DOM).
