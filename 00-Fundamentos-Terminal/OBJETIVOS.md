# 🎯 Objetivos Pedagógicos: Fundamentos de Terminal

## Propósito del Módulo
Lograr que el estudiante pierda el miedo a la línea de comandos, entendiendo cómo el sistema operativo maneja archivos y procesos sin necesidad de una interfaz gráfica (GUI).

## Metas de Aprendizaje
1. **Navegación:** Moverse entre directorios fluidamente (`cd`, `pwd`, `ls`/`dir`).
2. **Manipulación de Archivos:** Crear, mover, copiar y eliminar archivos/carpetas directamente desde la terminal (`mkdir`, `touch`, `rm`, `cp`, `mv`).
3. **Productividad:** Acelerar el flujo de trabajo como desarrollador al no depender del mouse.

## ¿Cómo saber que dominas esto?
Eres capaz de crear una estructura de proyecto (carpeta principal, subcarpetas CSS/JS, archivos base) completamente desde la consola en menos de un minuto.
