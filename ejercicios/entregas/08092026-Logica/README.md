# Mini Retos de Lógica de Programación

Este repositorio contiene la solución a dos retos básicos de lógica de programación implementados en JavaScript.

## Retos

1. **Contador de Vocales:** Un programa que recibe como entrada una palabra y determina cuántas vocales hay en ella.
2. **Detector de Palíndromos:** Un programa que evalúa si una palabra dada es un palíndromo (se lee igual al derecho y al revés).

## Archivos

- `index.html`: Interfaz gráfica de usuario sencilla para probar las funciones.
- `logica-programacion.js`: Lógica principal con las funciones `contarVocales` y `esPalindromo`.
- `LICENSE`: Licencia del proyecto (MIT).

## Cómo probar

Simplemente abre el archivo `index.html` en tu navegador web de preferencia, ingresa una palabra en el campo de texto y presiona "Evaluar".

También puedes abrir la consola de desarrollo del navegador (`F12`) para ver los resultados de los casos de prueba solicitados que se ejecutan automáticamente al cargar el script.
