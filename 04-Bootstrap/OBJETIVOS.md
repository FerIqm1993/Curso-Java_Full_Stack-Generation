# 🎯 Objetivos Pedagógicos: Bootstrap

## Propósito del Módulo
Acelerar el desarrollo Frontend utilizando un framework CSS, permitiendo crear sitios atractivos, consistentes y responsivos con menos líneas de código.

## Metas de Aprendizaje
1. **Sistema de Cuadrículas (Grid System):** Entender filas (rows) y columnas (cols) para la maquetación.
2. **Componentes Pre-diseñados:** Integrar barras de navegación, botones, modales y tarjetas rápidamente.
3. **Clases Utilitarias:** Usar clases para márgenes, paddings, colores y display (flex, block) sin tocar el archivo CSS.

## ¿Cómo saber que dominas esto?
Puedes levantar una "Landing Page" completamente funcional y responsiva, con navegación y secciones de contenido atractivo, en menos de una hora sin escribir código CSS personalizado.
