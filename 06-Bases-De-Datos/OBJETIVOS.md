# 🎯 Objetivos Pedagógicos: Bases de Datos (SQL)

## Propósito del Módulo
Almacenar, consultar, modificar y persistir la información de las aplicaciones de forma estructurada y segura.

## Metas de Aprendizaje
1. **Modelado Relacional:** Diseñar tablas lógicas con llaves primarias (PK) y llaves foráneas (FK).
2. **CRUD (Create, Read, Update, Delete):** Escribir comandos DML (INSERT, SELECT, UPDATE, DELETE).
3. **Consultas Avanzadas:** Realizar filtrados (WHERE), agrupaciones (GROUP BY) y cruces de tablas (JOIN).

## ¿Cómo saber que dominas esto?
Dada una regla de negocio (ej. "Un e-commerce necesita guardar usuarios, productos y las compras que hacen"), puedes diseñar las tablas necesarias en SQL y hacer una consulta que muestre "Qué productos compró X usuario".
