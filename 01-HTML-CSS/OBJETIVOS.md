# 🎯 Objetivos Pedagógicos: HTML y CSS

## Propósito del Módulo
Comprender la estructura semántica de la web (HTML) y la presentación visual (CSS) para construir interfaces de usuario sólidas, accesibles y responsivas.

## Metas de Aprendizaje
1. **HTML Semántico:** Usar las etiquetas correctas (header, nav, main, footer) para mejorar el SEO y la accesibilidad.
2. **Estilización (CSS):** Dominar selectores, modelo de caja (Box Model) y posicionamiento.
3. **Diseño Responsivo:** Entender cómo usar Flexbox y CSS Grid, además de Media Queries para adaptar sitios a móviles.

## ¿Cómo saber que dominas esto?
Puedes tomar una imagen de un diseño web (mockup) y traducirla a código HTML/CSS logrando un resultado idéntico, que además se vea bien en un celular.
