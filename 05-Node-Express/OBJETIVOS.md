# 🎯 Objetivos Pedagógicos: Node.js y Express

## Propósito del Módulo
Comprender el desarrollo del lado del servidor (Backend) utilizando JavaScript, exponiendo datos y servicios para ser consumidos por el Frontend.

## Metas de Aprendizaje
1. **Node.js (Runtime):** Ejecutar JS fuera del navegador, manejar el sistema de archivos e instalar paquetes con NPM.
2. **Express.js (Framework):** Configurar un servidor web para escuchar peticiones HTTP (GET, POST, PUT, DELETE).
3. **Creación de API REST:** Estructurar rutas, recibir parámetros y devolver respuestas estructuradas en formato JSON.

## ¿Cómo saber que dominas esto?
Puedes construir una API básica con rutas que respondan con arreglos de datos en JSON (ej. lista de usuarios, lista de productos), lista para conectarse a un frontend o base de datos.
