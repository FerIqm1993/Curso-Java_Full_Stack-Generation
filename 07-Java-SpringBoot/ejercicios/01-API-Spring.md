# Ejercicio 1: Mi Primera API con Spring Boot

**Instrucción:** Crea un controlador REST que responda a la ruta `/api/saludo` y devuelva el texto "Bienvenido a Spring Boot".

**Requisitos:**
- Usar la anotación `@RestController`.
- Usar `@GetMapping`.

*Tip: Genera tu proyecto base en start.spring.io con Spring Web.*
