# 🎯 Objetivos Pedagógicos: Java Spring Boot

## Propósito del Módulo
Construir servicios Backend a nivel empresarial de manera rápida y escalable, utilizando el robusto ecosistema de Java.

## Metas de Aprendizaje
1. **Arquitectura de Spring:** Comprender la Inversión de Control (IoC) y la Inyección de Dependencias.
2. **Arquitectura MVC (Modelo-Vista-Controlador) / API:** Estructurar el proyecto en capas (Controladores, Servicios, Repositorios).
3. **Spring Data JPA:** Conectar el código Java con bases de datos relacionales sin escribir SQL manual (ORM).

## ¿Cómo saber que dominas esto?
Puedes crear un CRUD completo de una entidad (ej. Productos) expuesto a través de endpoints REST (`@RestController`) y conectado a una base de datos MySQL/PostgreSQL mediante Spring Data.
