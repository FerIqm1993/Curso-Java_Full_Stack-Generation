# 🎯 Objetivos Pedagógicos: Java Core

## Propósito del Módulo
Aprender un lenguaje de programación fuertemente tipado, estructurado y orientado a objetos, fundamental en entornos empresariales (Backend).

## Metas de Aprendizaje
1. **Tipado y Compilación:** Entender los tipos de datos primitivos, variables de referencia y el proceso de compilación (JVM).
2. **Control de Flujo Estricto:** Manejo de bucles (for, while) y condicionales (switch, if).
3. **Programación Orientada a Objetos (POO):** Clases, objetos, herencia, encapsulamiento y polimorfismo.

## ¿Cómo saber que dominas esto?
Puedes diseñar y codificar un sistema básico por consola (ej. un sistema de inventario o cajero automático) aplicando clases, métodos constructores y herencia sin errores de compilación.
