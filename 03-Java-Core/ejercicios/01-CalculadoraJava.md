# Ejercicio: Calculadora en Java

## Instrucciones:
Crea un programa en Java que funcione como una calculadora básica. El objetivo es declarar dos variables numéricas y realizar operaciones matemáticas elementales.

## Tu tarea:
1. Declara y asigna dos variables enteras (`int`) con los valores que prefieras.
2. Calcula y muestra en consola el resultado de sumar ambas variables.
3. Calcula y muestra en consola el resultado de restar ambas variables.
4. Calcula y muestra en consola el resultado de multiplicar ambas variables.
5. Calcula y muestra en consola el resultado de dividir ambas variables.

**Objetivo:** Practicar la declaración de variables y el uso de los operadores aritméticos básicos en Java (`+`, `-`, `*`, `/`).
