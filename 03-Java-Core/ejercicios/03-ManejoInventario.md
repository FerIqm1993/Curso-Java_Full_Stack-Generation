# Ejercicio: Manejo de Inventario

## Instrucciones:
Utiliza las Colecciones de Java, específicamente `HashMap`, para crear un pequeño sistema de manejo de inventario de productos.

## Tu tarea:
1. Crea un `HashMap` donde la llave (Key) sea el nombre del producto (`String`) y el valor (Value) sea la cantidad disponible en inventario (`Integer`).
2. Agrega al menos 3 productos diferentes con sus respectivas cantidades iniciales.
3. Implementa una búsqueda: Dado el nombre de un producto, busca si existe en el `HashMap` e imprime su cantidad disponible.
4. Actualiza la cantidad de un producto (simulando una venta o un reabastecimiento).
5. Elimina un producto del inventario.
6. Recorre e imprime todos los productos y sus cantidades usando un ciclo (ej. `for-each`).

**Objetivo:** Practicar el uso de Colecciones en Java (API Collections), específicamente el manejo de estructuras de datos clave-valor con `HashMap`.
