# Ejercicio #2: Cálculo de la cuenta de un restaurante

## Instrucciones:
Crea un programa en Java para calcular el total a pagar en una cena. Imagina que compraste una hamburguesa, unas papas fritas y un refresco. Debes usar variables y operadores aritméticos para resolver los cálculos.

Declara y asigna las siguientes variables con valores decimales:
- El precio de la hamburguesa.
- El precio de las papas.
- El precio del refresco.

## Tu tarea:
1. Calcula el **subtotal** sumando los precios de los tres productos y guárdalo en una nueva variable.
2. Aplica un descuento fijo creando una variable para el **porcentaje de descuento** (por ejemplo, 0.10 para el 10%) y calcula el **monto a descontar** (subtotal multiplicado por el descuento).
3. Calcula el **total final** restando el descuento al subtotal y sumando un monto fijo para la **propina** (por ejemplo, 5.50).
4. Muestra en la consola el subtotal, el dinero ahorrado por el descuento y el total neto a pagar con mensajes claros.

**Objetivo:** Aprender a realizar operaciones matemáticas básicas (+, -, *) en Java y entender cómo el resultado de una operación se puede almacenar en una nueva variable para usarla después.
