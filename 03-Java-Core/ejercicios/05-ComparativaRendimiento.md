# Ejercicio: Comparativa de rendimiento de dos atletas

## Instrucciones:
Crea un programa en Java para evaluar el desempeño de dos corredores en un entrenamiento. Utilizarás operadores aritméticos y de comparación para medir y contrastar sus resultados.

Declara y asigna variables para almacenar los datos de cada atleta:
- La distancia recorrida por el Atleta A en metros y el tiempo que tardó en segundos.
- La distancia recorrida por el Atleta B en metros y el tiempo que tardó en segundos.

## Tu tarea:
1. Calcula la **velocidad promedio** del Atleta A (distancia dividida entre tiempo) y guárdala en una variable decimal.
2. Calcula la **velocidad promedio** del Atleta B de la misma manera y almacénala en otra variable decimal.
3. Crea una variable booleana llamada `atletaAMasRapido` que compare si la velocidad del Atleta A fue mayor (`>`) que la del Atleta B.
4. Crea otra variable booleana llamada `mismoRendimiento` para comprobar si ambos atletas corrieron exactamente a la misma velocidad (`==`).
5. Imprime en la consola la velocidad de cada uno y los resultados de ambas comparaciones booleanas con mensajes claros.

**Objetivo:** Aplicar operadores aritméticos para calcular razones matemáticas y dominar los operadores de comparación de magnitud e igualdad (`>`, `==`) para confrontar variables numéricas.
