# Ejercicio: Recomendación de Películas

**Instrucción:**
Crea un programa que reciba como input una **categoría de películas** y **muestre una recomendación** de acuerdo con la categoría ingresada.

**Categorías disponibles:**
- drama.
- comedia.
- romance.
- suspenso.
- terror.

---

### Guía para resolverlo:

**Nombre sugerido para el archivo:** `07-RecomendacionPeliculas.java` (recuerda que si le pones `public class`, el archivo debe llamarse igual que la clase, sin números al inicio, por ejemplo `RecomendacionPeliculas.java`).

**Pasos sugeridos:**
1. Importar e instanciar la clase `Scanner` para leer el input del usuario.
2. Pedir al usuario que ingrese una de las categorías listadas.
3. Guardar el input en una variable de tipo `String`.
4. Utilizar una estructura de control de flujo, como un `switch` o `if-else if`, para evaluar la categoría ingresada.
5. Imprimir en consola una película recomendada correspondiente a esa categoría.
6. (Opcional) Agregar un caso `default` o un `else` final por si el usuario ingresa una categoría que no está en la lista.
7. Cerrar el `Scanner`.
