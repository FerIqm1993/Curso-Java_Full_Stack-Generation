# 🎯 Objetivos Pedagógicos: React

## Propósito del Módulo
Aprender la librería más popular para construir interfaces de usuario (UI) modernas, manejando eficientemente el estado y creando Single Page Applications (SPA).

## Metas de Aprendizaje
1. **Componentización (JSX):** Dividir una interfaz compleja en pequeñas piezas reutilizables.
2. **Manejo del Estado (State):** Usar Hooks (como `useState` y `useEffect`) para que la aplicación reaccione a cambios (clicks, obtención de datos).
3. **Consumo de APIs:** Conectar tu interfaz React con un backend (Node o Spring) y mostrar información dinámica de la base de datos.

## ¿Cómo saber que dominas esto?
Puedes construir el frontend completo de una tienda o aplicación de tareas que se actualice sola sin recargar la página, haciendo peticiones asíncronas (`fetch` / `axios`) a un API.
