# 🏆 Proyecto Integrador Final: E-Commerce Completo
**Descripción:** Diseñar y construir una tienda en línea desde cero.

**Requisitos:**
- **BD:** Esquema relacional con Usuarios, Roles, Productos, Órdenes y Detalles_Orden.
- **Backend (Spring Boot):** 
  - CRUD completo de productos (sólo Admin).
  - Autenticación JWT.
  - Endpoint para procesar un carrito de compra y crear una Orden.
- **Frontend (React + Bootstrap):**
  - Catálogo de productos paginado y con buscador.
  - Carrito de compras usando Context API.
  - Pantalla de Checkout / Historial de compras.
- **Opcional (Mid-level):** Subida de imágenes a un bucket (AWS S3 / Cloudinary) y despliegue a producción (Render, Vercel o AWS).
